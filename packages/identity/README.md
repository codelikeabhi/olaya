# Olaya identity

Every logo, icon and favicon in this repository is generated by [`build.py`](build.py) from one
geometry. Don't edit the generated files by hand: change the geometry and rebuild.

```sh
uv run --with resvg-py --with pillow python packages/identity/build.py
```

## The mark

A light ring (the "o" of Olaya), with a bold logistic curve crossing it and a coral point on the
curve. The curve is the decision layer's probability curve. The point sits at the certified
auto-approve threshold, p = 0.85. A small gap separates the point from the curve, so it still
reads when the mark is one colour.

| file | use |
|---|---|
| `olaya-logo.svg`, `olaya-logo-dark.svg` | horizontal lockup, for light and dark backgrounds. The default. |
| `olaya-logo-stacked*.svg` | stacked lockup, for square spaces |
| `olaya-symbol*.svg` | the symbol alone, 48 px and up |
| `olaya-app-icon.svg`, `mark-*.png` | app icon tile |
| `mark.svg`, `mark-light.svg` | compact mark for toolbars (VS Code buttons), 16–40 px |

Generated elsewhere:
- desktop icons for the prod, beta and dev channels (`packages/desktop/icons`);
- web favicons and the manifest (`packages/ui/src/assets/favicon`);
- the GitHub social preview (`packages/ui/src/assets/images/social-share.png`);
- the app's `Mark`, `Splash` and `Logo` components (`packages/ui/src/components/logo-geometry.ts`).

The terminal form is drawn in half-blocks in `packages/tui/src/logo.ts`.

## Rules

- **Clear space:** keep at least the point's diameter free on every side.
- **Size:** below 48 px, use the compact mark (no ring, heavier curve), never the full symbol shrunk.
- **Colour:** use only the colours below. Allow green and Ask amber are decision states in the
  product, never brand colours.
- **Don't:** recolour the point, reshape the curve, move the point, or set the wordmark in another
  typeface.

| colour | hex | role |
|---|---|---|
| Indigo | `#25236B` | brand ink |
| Night | `#16143D` | dark ground, app icon |
| Coral | `#D9573B` | the point, on light |
| Coral 300 | `#F08A70` | the point, on dark |
| Chalk | `#FAFAF7` | light ground, ink on dark |

## Type

- **Wordmark and display:** Instrument Serif.
- **Interface and text:** Instrument Sans.
- **Code:** Martian Mono.

All three are SIL Open Font License 1.1. The wordmark and the social-card copy are stored as
outlines in `type.json`, so no font ships with the repo. `build.py outline` regenerates them.
